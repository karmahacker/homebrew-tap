# Homebrew tap for Brain

This tap distributes the precompiled [Brain](https://github.com/karmahacker/brain)
CLI. The source repository and operational data stay private; the formula
references only immutable, checksummed release binaries.

After the first R2-backed release is published:

```bash
brew tap karmahacker/tap
brew install brain
brew upgrade brain
```

`Formula/brain.rb` is generated by Brain's release workflow. Do not add
credentials, vault contents, or mutable download URLs to this repository.
